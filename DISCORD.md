## English

**Bloodborne Launcher is out.**

This is an open-source Windows launcher that installs the Bloodborne PC port for you. Other launchers expect the dump, the update, and the port to already be in the right folders. This one downloads them from inside the app and finishes the install on its own: GOTY base PKG, v1.09 update, the port, and the extractor. A dropped download resumes, and a closed window keeps running from the system tray.

The setup on the release page only installs the launcher. The game is fetched after you pick a folder. Plan on about 65 GB of free space.

Download: https://github.com/furylemonss/bloodborne-launcher/releases/tag/v1.0.0

Source: https://github.com/furylemonss/bloodborne-launcher
